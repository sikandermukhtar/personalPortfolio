## Overview

GradeWave is an AI-assisted grading and feedback platform designed around a modern full-stack architecture. The project combines a FastAPI backend, React web interface, Expo React Native mobile app, and background processing infrastructure for AI-heavy workflows.

The system is built to support grading and feedback tasks that may take longer than a normal request/response cycle. Instead of forcing everything through the frontend, the platform uses worker-based processing so AI tasks, retrieval steps, and feedback generation can run asynchronously.

## Technologies

- **FastAPI** for the backend layer.
- **React** for the web user interface.
- **Expo React Native** for the mobile application. 
- **Celery** to run background jobs for longer-running tasks.
- **Redis** to support queueing for the backgorund jobs.
- **LangChain** to build the RAG systems and the LLM workflows. 

## Why It Matters

Grading systems are not just CRUD applications. They need to manage files, context, rubric-like instructions, feedback quality, and asynchronous AI processing. GradeWave explores that intersection: a practical product surface backed by distributed task execution and retrieval-augmented AI workflows.
